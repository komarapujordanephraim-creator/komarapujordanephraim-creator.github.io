Flagship · post-quantum security

QuantumShield

A command-line scanner that finds cryptography a future quantum computer is expected to break, plus common classical mistakes, and tells you what to migrate to.

FIPS 203 · ML-KEMFIPS 204 · ML-DSAFIPS 205 · SLH-DSAPython 3.8+ · no dependencies
  • Harvest now, decrypt later. Traffic recorded today can be read once quantum computers are strong enough. The first step is knowing where RSA, elliptic curves and Diffie-Hellman live in your code.
  • Covers 20+ languages and config formats, from Python, Java and Go to Terraform, YAML and PEM files.
  • Fits into CI. JSON output and a --fail-on exit code, plus a single-file HTML report.
  • Honest about limits. Detection is pattern-based. A clean result does not prove a system is quantum-safe.
